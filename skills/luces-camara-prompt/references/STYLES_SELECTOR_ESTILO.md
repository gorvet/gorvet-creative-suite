# SELECTOR DE ESTILO

## ¿Qué emoción?
- intensidad / drama / tensión → Cinematic;
- belleza / contemplación / sensibilidad → Fine Art.

## ¿Para quién?
- comercial / campaña → Editorial;
- social / lifestyle → Influencer o Natural según tono.

## ¿Real o soñada?
- real → Photo / Natural;
- fantástica / simbólica → Conceptual / Artistic.

## ¿Vender o emocionar?
- vender → Editorial / Fashion / Product;
- emocionar → Cinematic / Fine Art.

## Por sector
- moda → luz difusa + textura de tela + pose editorial;
- arquitectura/interior → líneas + luz natural controlada + geometría;
- branding/packaging → mockup limpio + fondo neutro + luz lateral;
- música/arte → concierto + geles + humo/neón;
- gastronomía/bebidas → macro + vapor/gotas + tono cálido;
- educación/cultura → ilustración/animación + paleta amable;
- turismo → luz natural + plano amplio;
- tecnología → fría + oscuro/degradado + neón sutil;
- belleza/cosmética → suave + piel + neutros;
- salud/bienestar → claridad + calma + limpieza;
- negocios/servicios → profesional + limpio + azul/gris;
- deporte/fitness → movimiento congelado + luz dura + transpiración;
- eventos → color vibrante + multiluces + energía;
- artesanal → cálida + naturaleza + textura/proceso;
- causa social → documental / B&N + foco humano;
- infantil → vivo + juguetón + encuadre alegre;
- streetwear → lateral dura + cemento/ladrillo + contraste;
- conceptual → simbólico + paleta limitada;
- IA/creatividad digital → sintético + glitch/neón + composición imposible.

## Fusión
Regla:
`1 estilo dominante + 1 matiz técnico + 1 atmósfera`

Ejemplo de estructura:
`Editorial photo with cinematic lighting and fine-art color grading.`
