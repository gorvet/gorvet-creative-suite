# ERRORES, REGLAS Y CORRECCIONES

## Demasiados adjetivos
Problema: confusión.
Corrección: mantener 3–5 modificadores útiles y eliminar redundancia.

## Negaciones
Problema: pueden producir contradicción o introducir el objeto negado.
Corrección: describir lo que sí debe verse.
Excepción: edición localizada o restricciones indispensables.

## Estilos múltiples
Problema: códigos visuales incompatibles.
Corrección:
- un estilo dominante;
- un matiz compatible;
- una atmósfera.

## Luz/entorno ausentes
Problema: escena genérica.
Corrección: contexto físico + hora + fuente de luz.

## Emociones vagas
Problema: resultado plano.
Corrección: traducir emoción a gesto, luz, clima y color.

## Acción vaga
Problema: pose genérica.
Corrección: describir actitud y acción concreta.

## Prompt sin resultado esperado
Probar:
- sinónimo más visual;
- reordenar bloques;
- separar narrativa y técnica;
- reducir información secundaria.

## Técnica redundante
No añadir cámara, lente, resolución o efectos solo para “sonar profesional”.

## Estilo frente a intención
Si una instrucción estética compite con el propósito principal, gana el propósito.
