# REFERENCIAS VISUALES

## Tipos
Una referencia puede ser:
- imagen cargada;
- descripción exacta repetida;
- estilo visual constante.

El mayor control aparece al definir claramente su propósito.

## Jerarquía
`[CONTEXTO GENERAL] + [PROPÓSITO DE LA REFERENCIA] + [RESTO DE INSTRUCCIONES]`

## Identidad
Formulaciones útiles:
- `use the facial identity and hairstyle from the provided reference image`
- `preserve the same face and facial proportions`
- `consistent appearance`

Después especificar:
- pose;
- ropa;
- luz;
- entorno;
- estilo.

## Producto
Indicar:
- diseño exacto;
- forma;
- proporciones;
- branding;
- color;
- material.

Luego definir nueva escena.

## Pose
Indicar que la referencia solo gobierna:
- postura;
- gesto;
- anatomía;
- ángulo.

## Composición
Conservar:
- layout;
- perspectiva;
- cámara;
- ubicación de elementos;
cuando sea la intención.

## Estilo / mood
Usar la referencia solo para:
- paleta;
- luz;
- acabado;
- textura;
- atmósfera.

No asumir que debe heredarse sujeto o composición.

## Boceto
Conservar:
- líneas estructurales;
- geometría;
- proporciones;
- relaciones espaciales.

Aplicar después:
- materiales;
- iluminación;
- acabado.

## Fuerza de referencia
Si el texto es vago y la referencia es muy definida, la referencia puede dominar.
Solución:
- detallar con precisión los atributos que deben cambiar.
