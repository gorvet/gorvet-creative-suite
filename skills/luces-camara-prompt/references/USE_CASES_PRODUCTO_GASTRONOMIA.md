# PRODUCTO, GASTRONOMÍA Y BEBIDAS

## Producto
Objetivo:
- claridad;
- deseo;
- valor percibido.

Estructura:
`[producto/marca] + [material/textura] + [luz/fondo] + [ambiente/estilo] + [técnica]`

Prioridades:
- fondo neutro o textura suave cuando convenga;
- soft studio / diffused daylight;
- describir vidrio, metal, tela, cerámica;
- front / 45° / macro;
- reflejo controlado.

## Gastronomía
Objetivo:
- apetito;
- textura;
- temperatura percibida.

Estructura:
`[plato/bebida] + [luz/entorno] + [presentación] + [tono] + [detalle sensorial]`

Recursos:
- warm side light;
- cinematic food lighting;
- crispy;
- juicy;
- melting;
- glossy;
- steam;
- condensation;
- rustic surface;
- shallow depth.

## Microemociones
Traducir sensaciones:
- frío;
- fresco;
- caliente;
- casero;
- artesanal.

## Regla
Luz + material + ángulo + contexto suele controlar mejor que una cadena de adjetivos.
