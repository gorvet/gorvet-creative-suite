# DISEÑO EDITORIAL, MOCKUPS Y LOGOS

## Carteles / portadas
Estructura:
`[tema/concepto] + [paleta/textura] + [tipografía/composición] + [estilo]`

Prioridades:
- layout;
- jerarquía;
- espacio negativo;
- integración o reserva para texto.

Sentencia útil:
`poster layout with integrated text area`

## Texto generado
El libro advierte que textos largos o composiciones cargadas pueden producir errores.
Cuando la exactitud tipográfica sea crítica:
- generar imagen/layout;
- añadir texto en software de diseño.

## Mockup
Estructura:
`[diseño aplicado] + [soporte] + [luz] + [presentación]`

Prioridades:
- fotografía creíble del producto final;
- perspectiva;
- fibra/material;
- reflejos;
- luz ambiental;
- sombra de contacto.

## Logo / símbolo
El libro desaconseja depender de IA para conceptualización profesional de marca.

Si se usa para exploración:
Estructura:
`[concepto] + [símbolo/forma] + [tipografía/color] + [estilo] + [restricciones]`

Prioridades:
- simple;
- vector-like;
- escalable;
- legible;
- evitar clichés literales;
- sin efectos 3D si se busca logo plano.

Puede hacerse lluvia de ideas de símbolos antes de construir el prompt visual.
