# RENDER, INTERIORES, TEXTURAS PBR Y PROTOTIPOS

## Boceto → render
Estructura:
`[boceto] + [geometría/layout] + [materiales] + [luz] + [entorno] + [calidad/perspectiva]`

Conservar:
- composición;
- ángulos;
- relaciones espaciales;
- proporciones.

Añadir:
- concreto;
- madera;
- vidrio;
- reflejos;
- imperfecciones;
- PBR;
- iluminación física coherente.

## Textura PBR
Estructura:
`[material] + [condición/detalle] + [contexto] + [parámetros]`

Claves:
- seamless;
- tileable;
- albedo;
- roughness;
- physically accurate;
- procedural surface;
- realistic detail.

## Interiorismo
Estructura:
`[imagen base] + [espacio] + [estilo] + [mobiliario] + [luz/materiales] + [detalles]`

Conservar cuando corresponda:
- perspectiva;
- estructura de paredes;
- dirección de luz.

Especificar:
- materiales dominantes;
- distribución;
- escala;
- habitabilidad.

Evitar términos vagos como `beautiful room` o `nice interior`.

## Boceto → imagen final
Estructura:
`[boceto] + [referencias secundarias] + [propósito/escena] + [área de texto opcional] + [estilo/atmósfera] + [técnica]`

## Prototipo
Estructura:
`[referencia/boceto] + [material] + [superficie] + [iluminación] + [nivel de detalle]`

Para objetos artesanales:
- pequeñas imperfecciones;
- huellas;
- irregularidades;
- mate/brillo realistas.
