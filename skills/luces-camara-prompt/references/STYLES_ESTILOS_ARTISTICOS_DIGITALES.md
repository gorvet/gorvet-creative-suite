## Control de estilos animados
Regla del libro:
`textura + render + época`

Ejemplos de componentes:
- retro 80s anime cel shading;
- modern 3D clay render;
- vector minimalist flat design.

## Referencia de autor
Cuando el nombre de un creador no sea conveniente o sea insuficiente:
- describir los rasgos visuales concretos;
- técnica;
- composición;
- paleta;
- textura;
- intención;
- añadir un giro propio cuando el uso sea comercial.
