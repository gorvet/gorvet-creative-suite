# MÉTODO G.O.R.V.E.T.

## G — Guion visual
Definir la historia o instante antes de generar.
Preguntas internas:
- ¿qué quiero contar?
- ¿cuál es el instante exacto?
- ¿qué cambia si elimino el fondo o la acción?

## O — Observación
Definir:
- dónde;
- cuándo;
- clima;
- hora;
- elementos físicos;
- atmósfera espacial.

El entorno debe apoyar la intención.

## R — Recursos técnicos
Seleccionar solo los útiles:
- cámara/look de captura;
- lente;
- apertura/profundidad;
- luz;
- estilo;
- textura;
- gradación;
- composición.

## V — Valor emocional
Elegir emoción dominante.
Traducirla a:
- expresión;
- gesto;
- luz;
- clima;
- color;
- contraste.

No depender de palabras vagas como “bonito” o “feliz”.

## E — Estructura
Construir por capas:
- sujeto y acción;
- ambiente;
- luz;
- textura;
- color;
- emoción.

Cada frase debe añadir una capa nueva.

## T — Tono
Relacionar propósito con lenguaje visual:
- campaña → cinematic / editorial;
- retrato íntimo → natural / fine art;
- producto → studio / macro;
- storytelling → conceptual / documentary;
- marca personal → lifestyle / professional.

## Uso como briefing
La plantilla GORVET puede utilizarse como briefing visual previo al prompt.

## Diagnóstico
Cuando un resultado falla, revisar:
- G: ¿la historia se entiende?
- O: ¿el entorno aporta?
- R: ¿la técnica es coherente?
- V: ¿la emoción aparece?
- E: ¿la jerarquía favorece lo importante?
- T: ¿el acabado pertenece al universo correcto?
