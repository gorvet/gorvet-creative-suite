# MODA, LIFESTYLE Y PUBLICIDAD

## Moda / lifestyle
Objetivo:
- actitud;
- identidad;
- aspiración.

Estructura:
`[modelo/outfit] + [escenario] + [iluminación] + [actitud/emoción] + [estilo]`

Recursos:
- fashion editorial;
- runway/studio lighting;
- bold posture;
- model walking;
- vibrant contrast;
- cinematic.

Movimiento útil:
- walking;
- turning;
- hair flowing.

## Publicidad / campaña
Objetivo:
- historia de marca;
- impacto inmediato;
- jerarquía comercial.

Estructura:
`[producto/persona] + [escenario narrativo] + [estilo editorial/cinemático] + [emoción]`

Prioridades:
- foco principal;
- color;
- contraste;
- curiosidad;
- espacio para copy si hace falta;
- coherencia entre persona, producto y entorno.

## Hero product
Cuando el producto es protagonista:
- ubicarlo como punto focal;
- tamaño visible;
- enfoque nítido;
- contexto subordinado;
- textura/material impecables.

## Regla
La emoción y la historia deben apoyar la función comercial del objeto.
