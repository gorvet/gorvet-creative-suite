# Traducir el diseño a un encargo ejecutable

La herramienta no comparte automáticamente el razonamiento del diseñador ni lee estas bibliotecas. Recibe una especificación del resultado. Redacta una dirección afirmativa y concreta; un inventario de prohibiciones deja demasiadas decisiones sin resolver.

## Información que recibe

| Componente | Especificación necesaria |
| --- | --- |
| Soporte | Orientación, proporción y condiciones de uso pertinentes. |
| Idea y foco | Qué relación visual comunica la propuesta y qué se reconoce primero. |
| Textos visibles | Lista cerrada del copy final; función y tratamiento de cada texto. |
| Composición | Ubicación relativa, alineaciones, agrupaciones, relación de escala y áreas de lectura. |
| Lenguaje gráfico | Rasgos de tipografía, funciones del color y tratamiento de imagen decididos. |
| Referencias | Archivos realmente adjuntos y qué se conserva o toma de cada uno. |
| Fidelidad | Datos o propiedades que requieren preservación exacta. |

No rellenes campos innecesarios. Un encargo breve y resuelto puede ser suficiente; la longitud no demuestra precisión. La especificación tiene que permitir reconstruir las relaciones del diseño, no ser una expansión adjetivada del brief.

## Expresar relaciones, no etiquetas

«Título dominante» necesita un tratamiento observable: mayor masa tipográfica, posición elegida y separación suficiente. «Contacto secundario» necesita tamaño relativo menor, alineación y un lugar legible. «Diseño limpio» necesita saber qué elementos existen y cómo se relacionan. Usa proporciones o posiciones cuando aclaren la solución; no inventes coordenadas exactas que la herramienta no puede respetar.

Enumera el copy como texto literal del arte. Distingue esas cadenas de las instrucciones de composición para que la herramienta no dibuje nombres de roles. Fija las unidades de sentido que deben permanecer juntas. Evita repetir las mismas cadenas en descripciones de escenas y ejemplos adicionales.

Las imágenes adjuntas tienen un papel concreto: producto, identidad, pose o lenguaje gráfico. Un esquema analítico ayuda a comunicar relaciones; no autoriza incorporar sus etiquetas ni obliga a copiar sus proporciones.

## Cerrar el traspaso

Construye el encargo a partir del contenido final de PIEZA y del diseño elegido, no resumiendo el brief original. Guarda TEXTO COMPLEMENTARIO para la entrega al usuario. No envíes material descartado al generador, incluso bajo «no incluir…»: al nombrarlo puedes volver a activarlo.

Comprueba si cada elemento visible sirve al concepto o a la lectura necesaria. Si el encargo aún reproduce la secuencia de datos del usuario con un objeto o rótulo para cada uno, vuelve a la edición y a la composición. Si conserva datos de otro destino, reconstruye el encargo antes de ejecutar. La herramienta no tiene que decidir qué sacar.

## Ejecución e iteración

Usa la herramienta disponible para producir el resultado solicitado. Cuando sea posible adjuntar referencias visuales, adjunta las pertinentes y describe su función. Un enlace que la herramienta no puede abrir no equivale a una referencia visual suministrada.

Después de observar el resultado, pide el cambio específico que corrige el fallo y conserva lo logrado. Si hay texto incorrecto, no reinterpretes toda la campaña; si hay competencia de niveles, modifica su relación visual. Una nueva generación desde cero tiene sentido cuando falla la dirección completa, no como respuesta automática a cualquier detalle.
