# Selector de conocimientos de Luces

La coordinación de un encargo completo pertenece a [Dirección creativa](../../SKILL.md). Este archivo selecciona conocimientos, no activa una cadena de skills ni un recorrido de aprobación. El resultado solicitado y la decisión pendiente determinan el recurso, no el nombre del sector.

| Necesidad | Bibliotecas pertinentes |
| --- | --- |
| Intención y dirección | `CORE_METODO_GORVET.md`, `CORE_PRINCIPIOS_DIRECCION_CREATIVA.md`. |
| Compilación | `CORE_ESTRUCTURA_PROMPT.md`, `WORKFLOWS_CONTROL_CALIDAD.md`. |
| Captura fotográfica | `TECHNICAL_CAMARA_LENTES_ENFOQUE.md`, `TECHNICAL_ILUMINACION.md`, `TECHNICAL_ENCUADRE_COMPOSICION_RATIO.md`. |
| Acabado y materiales | `TECHNICAL_COLOR_TEXTURA_REALISMO.md`. |
| Lenguaje visual | `STYLES_ESTILOS_FOTOGRAFICOS.md`, `STYLES_ESTILOS_ARTISTICOS_DIGITALES.md`, `STYLES_SELECTOR_ESTILO.md`. |
| Uso de referencias | `REFERENCES_REFERENCIAS_VISUALES.md`, `REFERENCES_CONSISTENCIA_IDENTIDAD.md`, `REFERENCES_PRODUCTO_BRANDING.md`. |
| Aplicación pertinente | Solo el módulo `USE_CASES_*` que aporte criterio al problema. |
| Diagnóstico | `CORE_ERRORES_REGLAS.md`, `WORKFLOWS_ITERACION_DIAGNOSTICO.md`. |
| Vocabulario o consulta específica | `WORKFLOWS_PHRASE_BANK.md`, `WORKFLOWS_PROTIPS_OPERATIVOS.md`, `WORKFLOWS_EDITORIAL_INTIMO.md`, cuando corresponda. |

No hay bibliotecas técnicas obligatorias para todo encargo. Fotografía, ilustración, composición gráfica, render y edición tienen necesidades diferentes. Una asociación entre emoción y estilo es una posibilidad; una frase operativa es una alternativa, no una instrucción para añadirla al prompt.

La presencia de una fórmula antigua, un imperativo o una referencia a un flujo dentro de un recurso no cambia el alcance actual. El especialista conserva las decisiones del encargo y selecciona el conocimiento aplicable.
