# RETOQUE, POSTPRODUCCIÓN Y RESTAURACIÓN

## Retoque / compositing
Objetivo:
integrar referencias diferentes en una imagen coherente.

Estructura:
`[base/sujeto] + [elemento a sustituir o añadir] + [resultado final] + [coherencia técnica]`

Revisar:
- iluminación;
- color;
- escala;
- perspectiva;
- anatomía;
- comportamiento de tela;
- sombra;
- reflejo.

## Sustitución de vestuario
Indicar explícitamente:
- qué ropa se reemplaza;
- qué ropa nueva se usa;
- cómo cae;
- pliegues;
- relación con pose y entorno.

## Restauración
Objetivo:
recuperar una imagen sin perder identidad visual. Por defecto, conservar también el estilo y la iluminación originales. Colorización, modernización o cambio de acabado requieren que formen parte del encargo.

Estructura:
`[foto] + [qué preservar] + [daño/acciones] + [grado de restauración] + [acabado] + [técnica]`

Preservar:
- composición;
- proporciones;
- rasgos faciales;
- pose;
- elementos históricos esenciales.

Corregir:
- scratches;
- stains;
- folds;
- missing detail;
- paper damage;
- color;
- contrast;
- texture.

No introducir elementos nuevos salvo que el usuario lo solicite.
