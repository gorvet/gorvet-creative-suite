# Operaciones de escena y composición

Parte de la idea y el efecto perceptivo necesario. Estas operaciones se eligen, no se acumulan ni prescriben un estilo por sector.

| Necesidad | Decisión que puede resolverla | Control de aceptación |
| --- | --- | --- |
| Dar presencia a una forma o identidad | Ajustar distancia, escala y recorte conservando atributos reconocibles. | El sujeto domina sin deformación ni pérdida del rasgo necesario. |
| Hacer visible una textura o proceso | Acercamiento y luz o trazo que revelen su superficie. | El detalle comunica una propiedad pertinente y no una exageración ficticia. |
| Aportar movimiento o tensión | Relación diagonal, gesto o equilibrio asimétrico con un anclaje claro. | La dirección conduce al mensaje sin dispersar las masas. |
| Establecer calma o autoridad | Equilibrio de masas, ritmo, frontalidad o simetría deliberada. | Existe protagonismo y no una distribución automática de elementos equivalentes. |
| Crear profundidad | Relación de planos, oclusión, escala y foco compatibles con el medio. | La profundidad sostiene el sujeto y no fabrica accesorios innecesarios. |
| Integrar imagen y mensaje | Encuadre y zona de lectura diseñados juntos. | El texto tiene contraste y posición reales sin tapar atributos protegidos. |
| Comunicar una idea abstracta | Relación simbólica o transformación controlada de una propiedad. | Se comprende la asociación y se distingue la ficción conceptual de un hecho. |

Una escena simple puede ser intensa mediante forma, luz y relación espacial. Una escena compleja puede ser clara mediante agrupación y dominancia. No equipares anti-IA con fondo beige, minimalismo, eliminación de color o ausencia de detalle.

Previsualiza el conjunto como masas antes del acabado; después considera las relaciones que aportan interés. Si toda la diferencia entre dos propuestas depende de cambiar adjetivos, vuelve al argumento o a la organización espacial.
