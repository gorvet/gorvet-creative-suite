# Contrato de intervención sobre una imagen

Úsalo cuando la tarea sea modificar una imagen existente, no cuando una referencia solo aporte identidad o estilo. La operación conserva el marco visual aprobado y cambia únicamente lo solicitado.

## Antes de compilar

Identifica:

- **Base:** imagen aprobada y disponible, con identificador inequívoco.
- **Objetivo:** elemento, texto o región que debe modificarse; aclara una anotación ambigua antes de aplicarla.
- **Cambio:** estado visible deseado. Separa cambios distintos cuando puedan interferir.
- **Conservación:** identidad, composición, encuadre, luz, texto y objetos no afectados que deben permanecer.
- **Integración:** qué ajustes de borde, sombra o contacto necesita el cambio para pertenecer a la imagen.
- **Aceptación:** cómo se compararán objetivo, alcance y posibles alteraciones colaterales.

No añadas una fase de ideación por corregir una palabra. No conviertas «restaurar» en cambiar iluminación o modernizar el acabado. Si el objetivo requiere rediseñar la composición, informa del cambio de alcance y vuelve a propuesta.

## Después de editar

Compara con la base aprobada: primero el objetivo, después el contenido protegido y finalmente el conjunto. Una reparación local puede estropear el equilibrio, la identidad o la lectura aunque el detalle corregido parezca mejor.

Si hay deriva material, rechaza esa salida y vuelve a una base válida. No la conviertas en la nueva fuente de identidad ni acumules reparaciones sobre la deformación. Distingue una integración de borde necesaria de un cambio no autorizado en el resto del arte.

Las herramientas generativas no garantizan identidad de píxeles. Si la exactitud exige una intervención determinista y existe una herramienta adecuada, el director puede cambiar de vía manteniendo el alcance y verificando el resultado.
